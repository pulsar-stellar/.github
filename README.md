# Pulsar Stellar `.github`

This repository holds organization wide defaults for Pulsar Stellar on GitHub. The organization
profile that appears at https://github.com/pulsar-stellar is rendered from
[`profile/README.md`](profile/README.md); edit that file to change the org landing page.

Pulsar Stellar is an open source toolkit for reading Soroban contract events past the RPC
retention window. For the TypeScript SDK, the Go indexer and the web explorer see
[pulsar-app](https://github.com/pulsar-stellar/pulsar-app), for the Rust decoder and the reference
contract see [pulsar-core](https://github.com/pulsar-stellar/pulsar-core), and for the
documentation see [emeditweb.gitbook.io/pulsar-stellar-sdk](https://emeditweb.gitbook.io/pulsar-stellar-sdk).
